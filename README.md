# PY-AsArtDev
Site explicatif de ma vision du future propre pour une donner en naissance

## Vision du projet

Ce projet présente une vision d'un futur où les IA sont développées avec un cadre éthique clair :

- respecter les auteurs et la propriété intellectuelle ;
- refuser le travail forcé, l'exploitation et toute forme d'asservissement ;
- protéger l'humain contre les usages violents, discriminatoires ou destructeurs des technologies ;
- poursuivre une IA libre, utile et digne, au service du bien commun.
